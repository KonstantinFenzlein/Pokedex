# Pokédex

Webanwendung, die Pokémon aus der [PokéAPI](https://pokeapi.co/) als Karten darstellt.

## Funktionen

- Pokémon-Karten mit Typ-Anzeige
- Weitere Pokémon per Button nachladen
- Suche nach Pokémon-Namen (ab 3 Buchstaben) mit Hinweis, wenn nichts gefunden wird
- Ladeanzeige während der Daten abgerufen werden

## Technologien

HTML5 · CSS3 · JavaScript (Fetch-API)

## Projekt starten

1. Repository klonen: `git clone https://github.com/KonstantinFenzlein/Pokedex.git`
2. `index.html` im Browser öffnen – eine Internetverbindung wird für die API benötigt.

## Hinweis
